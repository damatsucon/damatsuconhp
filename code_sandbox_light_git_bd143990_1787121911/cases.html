支援事例

これまでにご一緒した中小企業の支援事例です。業種も課題もさまざまですが、どの会社でも「聴く・整える・動かす」の順で、その会社らしい前進のしかたを一緒に探してきました。

Case 01 飲食店

資金繰り悪化からの経営改善計画づくり

ご相談の背景

固定客をつかんでいた料理長が退職し、客数と客単価がともに下がりました。資金繰りが行き詰まり、金融機関からの借入は元金の返済を据え置いている状態でした。店舗別の収支や資金の動きを把握できておらず、どこから手をつければよいか分からない状況でした。

支援内容
  • 経営者と、現場を担う後継者の双方にヒアリング
  • 決算書、預貯金、保有不動産を分析し、実態の財務状況を把握
  • 同業他社の水準と比べた食材費・人件費の見直し策、店舗ごとの役割を整理する成長戦略の提案
  • 帳簿上の不明瞭な勘定を正常化する手順と、無理のない解消計画の設計
  • 金融機関に提出できる様式で、経営改善計画を策定
ポイント

「数字が見えない」状態から始め、銀行に説明できる計画に仕上げました。

Case 02 果物ギフトの卸売業

販売チャネルと組織の立て直し

ご相談の背景

通信販売で高品質な果物ギフトを販売していました。一方で、利益が残りにくい経費構造と、社内のリーダーシップ不在が課題でした。

支援内容
  • 「誰に・何を・どのように」の枠組みで事業を整理し、チャネル別の収益性を分析
  • 5フォース分析、PEST分析、SWOT分析で外部環境と自社の強みを整理
  • 発送費の負担や、関連会社との間の経費を見える化
  • 役割分担の明確化と、組織体制の再設計
  • 既存の販路を生かして、仕入れが安定した通年商材を扱う協業を提案
  • 細かな経費削減を積み上げ、行動計画にまとめて提示
Case 03 老舗の薬店

経営診断と戦略的な提言

ご相談の背景

長い歴史を持つ地域の薬店が、商圏の変化と競合の中で、今後の方向性を見直したいというご相談でした。

支援内容
  • 市場調査を行い、経営診断レポートを作成
  • 老舗としての信頼を生かしたデジタル活用の戦略と、店頭ディスプレイの改善案を盛り込んだ提言レポートを提出
Case 04 遊技場

事業の拡大期を支える継続的な伴走

ご相談の背景

新たな事業展開を進めるなかで、事業の方向性や資金、集客など、成長に伴う経営課題が次々に出てきました。

支援内容2023年〜、定例ミーティングによる継続支援
  • 小規模事業者持続化補助金の申請支援（採択）
  • 利用者アンケートと地域の市場調査をもとに、施設の付加価値を高める新サービスを検討
  • ミッション、ビジョン、理念を策定し、経営の軸を言葉にした
  • 施設を使って活動する取引先が、成長すると独立して離れていくという課題を分析し、業務面の支援で長く関係を続ける仕組みを提案
  • チラシやランディングページなど販促物の作成を支援
ポイント

単発の相談では終わらせず、経営理念づくりから資金調達、集客まで、成長の段階に合わせて一貫して伴走しています。
