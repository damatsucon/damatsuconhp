経営戦略 / 岡山経済 寄稿

戦略を策定している場合ではない!?

要約

中小企業経営において「戦略の策定が不可欠」といわれますが、「戦略は本当に大切なのか」「戦略は策定するものなのか」という2つの疑問からその幻想を検証します。

1. 中小企業経営に「戦略」は必要か？

戦略は万能の魔法の杖のように扱われがちですが、経営の文脈で使われ始めたのは約50年前に過ぎず、歴史上多くの経営は戦略概念なしに行われてきました。特に単一事業が多い中小企業では、問題の大半は日常業務（オペレーション）の管理にあり、戦略がオペレーションの失敗を補うことはできません。

一方で、戦略を「企業の将来像とそれを達成する道筋」と定義するならば、企業の永続性（ゴーイングコンサーン）の観点からは不可欠です。つまり、戦略は「それさえあれば大丈夫な魔法の杖」ではないものの、長期的な存続・発展には重要な要素です。

2. 戦略は「策定する」ものなのか？

環境分析を行い、計画的に戦略を「策定」して実行するという従来のアプローチは、現実の激しい環境変化や情報の不完全さを考慮できていません。変化の激しい状況下で机上の分析に終始して策定された戦略は、往々にして的外れになります。

現実のビジネスで有効なのは、行動を通じて学習しながら戦略が形作られていく「創発戦略」です。試行錯誤や偶然の契機から学習を重ねて競争優位を築く企業は多く存在します。戦略は机上で「策定する」ものではなく、行動を通じて「形成される」ものと捉えるのが現実的です。

戦略は机上で「策定する」ものではなく、
行動を通じて「形成される」もの。

3.「撃て！ 狙え！」

中小企業に必要なのは、戦略策定のために机にかじりつくことではなく、明確な将来像と確実なオペレーション管理を前提とした「まず行動を起こすこと」です。そして、計画通りに進まないことを前提に、実践プロセスから学習を深めていく姿勢が求められます。

変化の激しい時代を生き抜く中小企業は、従来の「計画→実行（狙って撃つ）」から、「実行→計画→実行（撃て！ 狙え！）」へと発想を転換することが重要です。
