経営計画 / 龍野商工会議所 会報への寄稿より

答えを急ぐ前に、問題を読め

テストで問題文をよく読まずに答えを書き始め、失敗した経験はないでしょうか。実は、経営計画づくりでも同じことが起きています。

経営計画は、事業領域の決定、現状分析、方向性の決定、課題の抽出、解決策の検討、行動計画の策定という流れで作ります。このなかで最も難しく、最も重要なのが「課題の抽出」です。あるべき姿と現状のギャップを明確にする、いわば「問題文を読む」作業です。

ところが多くの場合、課題の捉え方が曖昧なまま「値下げをする」「新商品を出す」「SNSを始める」といった解決策に飛びついてしまいます。これでは、的外れな打ち手を積み重ねるだけです。「何が問題なのか」を徹底的に考え抜くことに、計画づくりのエネルギーの大半を注ぐべきです。

「何が問題なのか」を徹底的に考え抜くことに、
計画づくりのエネルギーの大半を注ぐべきです。

問題を読む力は、計画を作った後にも求められます。計画通りにいかないのが経営の現実です。月次レビューを「答え合わせ」で終わらせず、「なぜズレたのか」を問い直す。環境が変わったのか、やり方がまずかったのか、それとも計画の前提が違っていたのか。そう考えることで、次の一手が見えてきます。

答えを急ぐ前に、まず問題を読む。それが、成り行き経営から抜け出す第一歩です。
