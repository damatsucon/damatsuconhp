プロフィール

経営の話を、
現場の言葉で。

独立から約30年、地方の中小企業支援に携わってきた歩みを、簡単にご紹介します。

現場と、学びの両方の言葉で。

中小企業の現場での実務経験、大学院で学んだ経営理論、そして教育の場での指導経験。三つの視点を行き来しながら、目の前の会社に合った言葉で経営を語ることを心がけています。

東京理科大学 理工学部 経営工学科を卒業後、百貨店での勤務を経て1996年に経営コンサルタントとして独立。1998年に中小企業診断士として登録し、以来約30年にわたり、中小企業の経営戦略、販路開拓、組織づくり、人材育成に携わってきました。

その後、経営コンサルティング会社にて経営指導の実務経験を重ね、執行役員としてエグゼクティブ・コンサルタントの立場から中小企業の経営指導にも従事。実務の現場で得た知見を積み重ねてきました。

岡山大学大学院 経営政策科学専攻にて修士（経営学）を取得。修士論文では中小製造業の持続的競争優位をテーマに研究し、実務だけでなく学術的な視点も取り入れながら、経営課題を構造的に捉えることを大切にしています。

商工会議所や支援機関、企業研修の場で登壇。岡山理科大学では非常勤講師として、プレゼンテーション、インターンシップ概論、キャリアデザインの教育にも携わっています。

仕事観

戦略も、人も、数字だけでは動きません。長年の実務のなかで大切にしてきた、2つの考え方をご紹介します。

感覚と理論、どちらも手放さない。

01

絵に描いた餅で、終わらせない。

立派な事業計画書や、きれいに整理された戦略図。それ自体は、決して悪いものではありません。ですが、それが「作ること」自体を目的にしてしまうと、途端に現場から浮いてしまいます。実際に何度も、「計画はできたが、誰も動かせなかった」という場面に立ち会ってきました。

大切なのは、絵を描いた後です。誰が、いつ、何を、どこまでやるのか。小さな一歩に分解し、現場の温度感に合わせて調整しながら、実際に動く仕組みに変えていく。ダーマツコンサルティングが最後まで責任を持つのは、この「絵から実行への橋渡し」の部分だと考えています。

02

感覚も大切。理論も大切。

経営者の「なんとなくこっちが良い気がする」という感覚は、長年その現場に立ってきた人だからこそ持てる、貴重な情報です。数字やフレームワークだけで、それを頭ごなしに否定することはしません。

一方で、感覚だけに頼ると、判断が属人的になり、再現性を失います。MBAで学んだ理論やフレームワークは、その感覚を「言葉」に変え、社内で共有できる形にするための道具です。感覚と理論、どちらか一方ではなく、両方を行き来しながら経営の意思決定を支えることを大切にしています。

支援内容

戦略の設計、売れる仕組みづくり、動ける人材の育成、そして講師業を支えるコンテンツづくりまで。単発のご相談でも、中長期の伴走でも、ご状況に応じて支援内容を設計します。

01

経営戦略・事業計画

現状分析から課題整理、中長期の方向性づくり、事業計画の言語化まで。経営者の頭の中にある構想を、社内外に伝わる戦略へと整えます。

02

販路開拓・営業強化

新規顧客の獲得、新市場への展開、営業活動の見直しなど、「売るための筋道」を明確にし、現場で動く打ち手まで伴走します。

03

人材育成・研修

戦略を実行できる人材を育てるために、階層別研修、幹部候補育成、プレゼンテーション研修などを、課題に合わせて設計します。

04

講演・補助金活用支援

商工会議所・金融機関・支援機関向けのセミナー登壇に加え、ものづくり補助金や小規模事業者持続化補助金などの申請支援にも対応しています。

05

研修・セミナー講師向け
コンテンツ作成支援

研修の全体構成、訓練主題の明確化、ハンドアウトの作成、説明用スライド資料、話す内容をまとめたスクリプトまで。研修・セミナーの登壇を控えた講師の方が、一人で抱え込みがちなコンテンツづくりに伴走します。

MBAで培った理論構成力、グローバルプレゼンテーション協会で磨いたプレゼンテーションスキル、そしてコンサルティングの現場で鍛えた課題抽出力。これら三つを統合し、伝わる研修・セミナー内容の策定をご支援します。

質の高いサービスと万全のサポート体制を維持するため、現在は完全紹介制とさせていただいております。

ご一緒する進め方

課題の整理から実行まで、次の3つのステップで進めます。状況や規模に応じて、途中のステップから始めることも可能です。

01

聴く

課題だけでなく、背景、迷い、これまでの経緯まで丁寧に伺います。表に見える問題だけではなく、本質的な論点を見つけます。

02

整える

経営戦略、販路、組織、人材の観点から論点を整理し、優先順位を明確にします。必要に応じて計画や資料に落とし込みます。

03

動かす

現場で無理なく動かせる施策へと変換し、実行と改善を支援します。研修や会議の場づくりまで含めて対応可能です。
