経営計画 / 寄稿より 答えを急ぐ前に、問題を読め テストで問題文をよく読まずに答えを書き始め、失敗した経験はないでしょうか。実は、経営計画づくりでも同じことが起きています。 続きを読む → 人材育成 / セミナーより 全員がリーダーになれるか ―「巻き込む力」という考え方 「リーダーシップは役職者のもの」という前提を外すと、組織の動き方が変わります。役職に関係なく場を動かす「巻き込む力」の考え方を整理します。 続きを読む → 経営戦略 / 岡山経済 寄稿 戦略を策定している場合ではない!? 中小企業経営において「戦略の策定が不可欠」といわれますが、「戦略は本当に大切なのか」「戦略は策定するものなのか」という2つの疑問からその幻想を検証します。 続きを読む →
