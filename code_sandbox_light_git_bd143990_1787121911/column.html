龍野商工会議所 会報への寄稿より / 経営計画

答えを急ぐ前に、問題を読め

テストで問題文をよく読まずに答えを書き始め、失敗した経験はないでしょうか。実は、経営計画づくりでも同じことが起きています。

経営計画は、事業領域の決定、現状分析、方向性の決定、課題の抽出、解決策の検討、行動計画の策定という流れで作ります。このなかで最も難しく、最も重要なのが「課題の抽出」です。あるべき姿と現状のギャップを明確にする、いわば「問題文を読む」作業です。

ところが多くの場合、課題の捉え方が曖昧なまま「値下げをする」「新商品を出す」「SNSを始める」といった解決策に飛びついてしまいます。これでは、的外れな打ち手を積み重ねるだけです。「何が問題なのか」を徹底的に考え抜くことに、計画づくりのエネルギーの大半を注ぐべきです。

問題を読む力は、計画を作った後にも求められます。計画通りにいかないのが経営の現実です。月次レビューを「答え合わせ」で終わらせず、「なぜズレたのか」を問い直す。環境が変わったのか、やり方がまずかったのか、それとも計画の前提が違っていたのか。そう考えることで、次の一手が見えてきます。

答えを急ぐ前に、まず問題を読む。それが、成り行き経営から抜け出す第一歩です。

セミナー「巻き込む力とリーダーシップ」より / 人材育成

全員がリーダーになれるか
―「巻き込む力」という考え方

要約

「リーダーシップは役職者のもの」という前提を外すと、組織の動き方が変わります。2026年11月に登壇したセミナーの内容から、役職に関係なく場を動かす「巻き込む力」の考え方を整理します。

1. リーダーシップは「働き」である

セミナーの冒頭で、参加者に「ここにいる全員がリーダーになれますか」と尋ねました。役職の席を思い浮かべれば、答えは「なれない」です。席はチームに一つか二つしかありません。

社会心理学者の三隅二不二が提唱したPM理論は、リーダーシップを人の資質ではなく、二つの「働き」として捉えます。仕事を前に進める働き（P：課題達成）と、チームをまとめて保つ働き（M：集団維持）です。働きであれば、役職がなくても果たせます。話が散らかって何も決まらない会議で「今日は何が決まればいいですか」と尋ねる。これはPの働きです。黙っている人に「どう思いますか」と声をかける。これはMの働きです。場に足りない働きを一つ補えば、それで十分です。

2. 巻き込む力とは何か

巻き込む力というと、自分のやりたいことに人を引き込む力だと思われがちです。セミナーでは、「役職や立場に関係なく、共通の目的に向けて、周囲の人が自ら参加したくなる状況をつくり、チームを動かす力」と定義しました。

要点は「共通の目的」と「自ら参加したくなる」の二つです。自分の都合に人を付き合わせることとも、命令で動かすこととも違います。相手が乗りやすくなる工夫は三つあります。目的を先に伝えること。時間や作業を明示して具体的に提案すること。そして、先に相手の考えを聞くことです。

3. 巻き込めたかどうかは、巻き込まれる側が決める

誰かが「こうしませんか」と名乗りを上げても、応じる人がいなければ、その提案は独り言のままです。うなずく、資料を渡す、最初に「やりましょう」と言う。こうした応答があって初めて、場は動きます。良い提案に最初の一人として乗ることも、聞かれる前に現場の情報を出すことも、役割を引き受けることも、巻き込む力の一部です。

ただし、何にでも従えばよいわけではありません。全員が素直に従う組織では、誤った判断がそのまま通ります。おすすめしているのは「乗りつつ、懸念を添える」ことです。「その案で進めましょう。ただ、この点だけ確認させてください」。賛同を先に示すと、懸念は提案を良くする材料として受け取られます。

4. 中小企業こそ、全員で分担する

一人のリーダーがすべてを見渡し、すべてを決める。規模の小さな会社ほど、この形になりがちです。しかし、現場の情報は社員一人ひとりに分散しています。場面ごとに適した人が前に出て、役割が入れ替わる組織のほうが、誰かが不在でも仕事は前に進みます。これをシェアド・リーダーシップといいます。

最初の問いに戻ります。役職の席は限られていますが、場を動かす行動は誰でもとれます。リーダーシップは、席ではなく行動です。だから全員が、場面に応じて巻き込み、巻き込まれることができます。

5. 明日の一言を決めておく

頭で分かっていても、その場になると動けないものです。そこで、場面と行動をセットで決めておきます。「もし会議で話が散らかったら、私は『今日は何を決めますか』と言う」。口に出すセリフまで書いておくのがコツです。言えなかったら、言いやすい一言に書き直して、もう一度試せば十分です。

この内容は、4時間の研修プログラムとして実施しています。研修プログラムの概要もあわせてご覧ください。

岡山経済 寄稿 / 経営戦略

戦略を策定している場合ではない!?

要約

中小企業経営において「戦略の策定が不可欠」といわれますが、「戦略は本当に大切なのか」「戦略は策定するものなのか」という2つの疑問からその幻想を検証します。

1. 中小企業経営に「戦略」は必要か？

戦略は万能の魔法の杖のように扱われがちですが、経営の文脈で使われ始めたのは約50年前に過ぎず、歴史上多くの経営は戦略概念なしに行われてきました。特に単一事業が多い中小企業では、問題の大半は日常業務（オペレーション）の管理にあり、戦略がオペレーションの失敗を補うことはできません。

一方で、戦略を「企業の将来像とそれを達成する道筋」と定義するならば、企業の永続性（ゴーイングコンサーン）の観点からは不可欠です。つまり、戦略は「それさえあれば大丈夫な魔法の杖」ではないものの、長期的な存続・発展には重要な要素です。

2. 戦略は「策定する」ものなのか？

環境分析を行い、計画的に戦略を「策定」して実行するという従来のアプローチは、現実の激しい環境変化や情報の不完全さを考慮できていません。変化の激しい状況下で机上の分析に終始して策定された戦略は、往々にして的外れになります。

現実のビジネスで有効なのは、行動を通じて学習しながら戦略が形作られていく「創発戦略」です。試行錯誤や偶然の契機から学習を重ねて競争優位を築く企業は多く存在します。戦略は机上で「策定する」ものではなく、行動を通じて「形成される」ものと捉えるのが現実的です。

3.「撃て！ 狙え！」

中小企業に必要なのは、戦略策定のために机にかじりつくことではなく、明確な将来像と確実なオペレーション管理を前提とした「まず行動を起こすこと」です。そして、計画通りに進まないことを前提に、実践プロセスから学習を深めていく姿勢が求められます。

変化の激しい時代を生き抜く中小企業は、従来の「計画→実行（狙って撃つ）」から、「実行→計画→実行（撃て！ 狙え！）」へと発想を転換することが重要です。
