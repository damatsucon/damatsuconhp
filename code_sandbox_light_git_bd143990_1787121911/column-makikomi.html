人材育成 / セミナー「巻き込む力とリーダーシップ」より

全員がリーダーになれるか
―「巻き込む力」という考え方

要約

「リーダーシップは役職者のもの」という前提を外すと、組織の動き方が変わります。2026年11月に登壇したセミナーの内容から、役職に関係なく場を動かす「巻き込む力」の考え方を整理します。

1. リーダーシップは「働き」である

セミナーの冒頭で、参加者に「ここにいる全員がリーダーになれますか」と尋ねました。役職の席を思い浮かべれば、答えは「なれない」です。席はチームに一つか二つしかありません。

社会心理学者の三隅二不二が提唱したPM理論は、リーダーシップを人の資質ではなく、二つの「働き」として捉えます。仕事を前に進める働き（P：課題達成）と、チームをまとめて保つ働き（M：集団維持）です。働きであれば、役職がなくても果たせます。話が散らかって何も決まらない会議で「今日は何が決まればいいですか」と尋ねる。これはPの働きです。黙っている人に「どう思いますか」と声をかける。これはMの働きです。場に足りない働きを一つ補えば、それで十分です。

2. 巻き込む力とは何か

巻き込む力というと、自分のやりたいことに人を引き込む力だと思われがちです。セミナーでは、「役職や立場に関係なく、共通の目的に向けて、周囲の人が自ら参加したくなる状況をつくり、チームを動かす力」と定義しました。

要点は「共通の目的」と「自ら参加したくなる」の二つです。自分の都合に人を付き合わせることとも、命令で動かすこととも違います。相手が乗りやすくなる工夫は三つあります。目的を先に伝えること。時間や作業を明示して具体的に提案すること。そして、先に相手の考えを聞くことです。

3. 巻き込めたかどうかは、巻き込まれる側が決める

誰かが「こうしませんか」と名乗りを上げても、応じる人がいなければ、その提案は独り言のままです。うなずく、資料を渡す、最初に「やりましょう」と言う。こうした応答があって初めて、場は動きます。良い提案に最初の一人として乗ることも、聞かれる前に現場の情報を出すことも、役割を引き受けることも、巻き込む力の一部です。

ただし、何にでも従えばよいわけではありません。全員が素直に従う組織では、誤った判断がそのまま通ります。おすすめしているのは「乗りつつ、懸念を添える」ことです。「その案で進めましょう。ただ、この点だけ確認させてください」。賛同を先に示すと、懸念は提案を良くする材料として受け取られます。

4. 中小企業こそ、全員で分担する

一人のリーダーがすべてを見渡し、すべてを決める。規模の小さな会社ほど、この形になりがちです。しかし、現場の情報は社員一人ひとりに分散しています。場面ごとに適した人が前に出て、役割が入れ替わる組織のほうが、誰かが不在でも仕事は前に進みます。これをシェアド・リーダーシップといいます。

最初の問いに戻ります。役職の席は限られていますが、場を動かす行動は誰でもとれます。リーダーシップは、席ではなく行動です。だから全員が、場面に応じて巻き込み、巻き込まれることができます。

リーダーシップは、席ではなく行動です。

5. 明日の一言を決めておく

頭で分かっていても、その場になると動けないものです。そこで、場面と行動をセットで決めておきます。「もし会議で話が散らかったら、私は『今日は何を決めますか』と言う」。口に出すセリフまで書いておくのがコツです。言えなかったら、言いやすい一言に書き直して、もう一度試せば十分です。

この内容は、4時間の研修プログラムとして実施しています。研修プログラムの概要もあわせてご覧ください。
